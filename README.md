# 🛒 Sistema Kiosco El Rapido
Repositorio principal del proyecto. El sistema esta dividido en dos modulos independientes:

- **[Frontend](./frontend/README.md):** Aplicación de cliente desarrollada en React, Vite, React Router y Tailwind/estilos personalizados.
- **[Backend](./backend/README.md):** API RESTful desarrollada con FastAPI, SQLite y Python.

## 🚀 Cómo poner en marcha el sistema completo
1. Clonar el repositorio.
2. Seguir las instrucciones del [Backend](./backend/README.md) para levantar el servidor de la API.
3. Seguir las instrucciones del [Frontend](./frontend/README.md) para correr la interfaz web.
